# 51 Agency — Official Website

A premium, modern, responsive one-page website built for **51 Agency** using React, Vite, and modern CSS.

---

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Start the local Vite development server
npm run dev
```

Visit the local development URL displayed in your terminal (`http://localhost:5173`).

---

## 📦 Production Build & Hostinger Deployment

```bash
npm run build
```

Upload the contents of `dist/` directly into `public_html/`.
